状态三色各有 -muted 变体（值见 globals.css），用于弱底/弱边。派生浅底浅边一律 color-mix 自语义 token。阴影 token：--shadow-low / med / high（oklch 多层 + 暗色 inset 白边），--shadow-float = med。

工程陷阱：--color-danger 未定义——写 text-danger / bg-danger 会静默 no-op。危险色唯一写法是 --color-error。

05

间距

布局间距一律使用 Astryx 数值 token（gap={n} / padding*={n}）。裸 Tailwind 间距类（gap-2、p-3）仅限图标-文字微调，且 ≤2 步。

场景写法说明
布局 / 容器gap={n} · padding*={n}唯一合法写法；数值经 Astryx token 校验
图标-文字微调bare tailwind ≤2 步仅限行内对齐（如 gap-1.5）；超出即改用数值 token
常用基准4 / 8 / 12 / 16 / 24卡片内 16、网格间 12、组件间 24；全部为 4 的倍数

z-index 语义层级

只允许以下语义档位，禁止裸数字。压层关系：selected > raised > 常规内容。

档位值用途
z-raised10卡片内覆盖：状态灯、角标、widget 拖拽手柄
z-selected20批量选择勾选框（必须压过 raised）
z-chrome50视口级 chrome：Logo、工具栏、横幅、全屏提示
背景层-10壁纸等背景（-z-10）
RGL 拖拽中100react-grid-layout 拖拽中的临时值
弹层规则：Astryx Dialog 是原生 <dialog>——modal 时位于浏览器 top layer，z-index 失效；仅 purpose='required' 时获得 role="alertdialog"。禁止手写弹层 z-index。

亮 = 白玻璃，暗 = #262626 玻璃；壁纸内容透过 15–20% 透明度形成景深（实机：全屏壁纸 + 毛玻璃 chrome）。
可访问性
Toast 容器 aria-live="polite"，错误 role="alert"；工具栏 role="toolbar" + aria-label；Tooltip 响应 hover 与 focus-visible。
11.5

表单控件 Button / Input / Dialog

accent 为中性黑白：primary 按钮即「黑底白字（亮）/ 白底黑字（暗）」。同屏仅一个 primary。弹窗宽度三档：320 / 440 / 560（sm/md/lg）。

全局搜索框（Ctrl K 徽标）— 页面视觉锚点：胶囊形 + emphasized 粗边框
URL 格式不正确，需包含协议头（https://）
焦点态：border accent + 2px accent-weak 光晕（focus-ring 统一规范见 11）。弹窗标题统一 1rem/600/1.5rem。
使用场景
primary（唯一主操作）/ secondary / ghost / danger（ghost 底 + --color-error）。搜索框为胶囊变体（field-pill）。
Token 映射
primary: --color-accent / --color-accent-contrast border: --color-border-emphasized radius: 10px（胶囊除外） disabled: --color-text-disabled
亮暗表现
accent 中性反色，primary 两主题自动互换黑白；hover 用亮度偏移（accent 无 hover token，禁硬编码色值）。
可访问性
弹窗宽度 sm 320 / md 440 / lg 560；弹窗必须用 Astryx Dialog（原生 <dialog>），禁手写弹层；表单提示用 sm(12px)，禁 2xs。

12

工程规约

来源：docs/design-conventions.md（2026-09-19 UI 审计建立的现行规范）+ globals.css / design-tokens.ts 审计。新代码逐条执行。

规约内容
危险色唯一只用 --color-error。--color-danger 未定义，text-danger/bg-danger 静默 no-op，禁止出现。
信息文本字号信息类文本禁 size="2xs"（8px；90% 字号偏好下 7.2px 不可读）。表单提示/空态/弹窗描述用 sm(12px)。2xs 仅限 widget 内部紧凑数据（Nothing 刻度）。
弹窗标题统一 1rem / 600 / 1.5rem（globals.css 已覆盖 DialogHeader / AlertDialog 默认，无需逐处设置）。
图标档位ICON_SIZE 12/14/16/18（xs 角标 / sm 菜单行 / md 工具栏 / lg 区块入口），来源 design-tokens.ts；不使用档外尺寸。
弹窗宽度档320 / 440 / 560（sm/md/lg），三档之外需先扩档再使用。
间距写法布局用 Astryx 数值 token（gap={n} / padding*={n}）；裸 Tailwind 间距仅限图标-文字微调 ≤2 步。
焦点态自写可聚焦元素统一 focus-ring：accent outline 2px + offset 2px，不得移除或改色。
StyleX 桥接Astryx 运行时 StyleX 样式未分层、压过 @layer utilities；冲突覆盖只能用内联 style 或更高特异性。承重内联清单（不得改 className）：AppShell 根透明背景、FloatingToolbar 菜单项 paddingInline:12 等。
弹层一律 Astryx Dialog（原生 <dialog>，top layer）；禁止手写弹层 z-index；role="alertdialog" 仅 purpose='required' 时存在。
z-index仅用语义档位（09 节），禁裸数字。
时钟颜色机制首页时钟 ink 用 light-dark() 跟随 color-scheme，不用 html[data-theme]——Astryx Theme 在 mode='system' 时会移除 data-theme，keyed 其上会错误落回亮色（globals.css 有完整注释）。
品牌 token 例外品牌自有 token（--color-brand-red / --color-brand-pixel、--home-clock-ink 系、--date-widget-* 系）不适用「禁止 override :root --color-*」限制。
滚动条widget 内容区用 .hover-scrollbar：默认隐藏、容器 hover/focus 显示（webkit 自绘 8px 圆角 thumb），避免永久滚动条打断视觉节奏。

可访问性基线

项目规范
对比度信息文本 ≥4.5:1，大字/图标 ≥3:1；text-secondary（#474747 / #9e9e9e）已按此校准。仅 --color-text-disabled 允许低对比。hover/focus 不降低前景对比。
焦点环全局 focus-ring：accent outline 2px + offset 2px；所有可聚焦元素不得移除。
状态双编码颜色 + 文字（StatusDot 必配标签）；错误信息具体可操作。
弹窗语义Astryx Dialog 原生焦点圈与 Esc 关闭；purpose='required' 才有 alertdialog 语义。
触控目标桌面 ≥36px；触屏 ≥44px（padding 扩展，不改视觉尺寸）。
动效过渡 ≤200ms；prefers-reduced-motion 下禁用位移与动画。
