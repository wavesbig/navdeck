# NavDeck 卡片与 Widget 交互规范

> 本规范统一卡片（Card）与小组组件（Widget）在排序、编辑、删除等操作的交互范式。
> 实施时以本文档为准，两侧遵循同一套规则。

---

## 1. 核心原则

| 原则 | 说明 |
|---|---|
| **统一性** | 卡片与 widget 在核心操作上遵循同一套交互范式 |
| **Web 端主流** | 以 web 端标准交互为基础（右键菜单、hover 反馈、键盘快捷键） |
| **防误触** | 拖拽需 distance 阈值（8px）激活，避免点击误触发拖拽 |
| **删除可撤销** | 删除走 toast 撤销方案（5 秒内可恢复），不弹二次确认 Dialog |
| **克制视觉** | 编辑态视觉反馈统一为 ring + scale + shadow，不堆砌额外控件 |

---

## 2. 编辑模式（Edit Mode）

### 2.1 定义

统一的"编辑模式"开关，**同时**管控卡片排序态和 widget 编辑态。一个开关统管，不再有独立的 widget 编辑入口。

### 2.2 入口与退出

| 操作 | 触发方式 |
|---|---|
| **进入** | FloatingToolbar 的"编辑模式"开关（一个按钮统管两侧） |
| **退出** | ESC 键 / FloatingToolbar 的"完成"按钮 / 再次点击开关 |

**同步性**：进入时卡片和 widget 同时进入编辑态；退出时同时退出。任一退出方式都同时关闭两边。

### 2.3 编辑态职责

编辑态的职责收窄为：**只管"拖拽 + resize"的开关**，不再管"删除入口的可见性"。

| 资源 | 编辑态启用 | 编辑态禁用 |
|---|---|---|
| 卡片 | 拖拽排序（跨分类） | 点击跳转 |
| widget | RGL 拖拽排序 + resize 把手 | — |

**删除/编辑操作**：不绑定编辑态，右键菜单在任何时候都可用。

### 2.4 非编辑态行为

| 资源 | 非编辑态 |
|---|---|
| 卡片 | 点击跳转 URL，不可拖拽，右键菜单可用 |
| widget | 静态展示，不可拖拽/resize，右键菜单可用 |

---

## 3. 右键菜单规范（ContextMenu）

### 3.1 统一结构

```
[编辑项]          ← 首项：编辑资源
─────────────
[资源特有操作]    ← 中间项：按资源类型不同
─────────────
[删除项]          ← 末项：destructive 样式（红色文字 + 垃圾桶图标）
```

结构相同（编辑 / 资源特有操作 / 删除），中间项按资源类型不同。参考 VSCode 资源管理器右键菜单范式。

### 3.2 卡片右键菜单

| 项 | 行为 |
|---|---|
| 编辑卡片 | 打开卡片编辑弹窗 |
| 复制 URL | 复制跳转 URL 到剪贴板 |
| 删除卡片 | 触发 toast 撤销删除流程 |

### 3.3 widget 右键菜单

| 项 | 行为 |
|---|---|
| 编辑配置 | 打开 widget 设置（如日期项管理等） |
| 调整尺寸 | 子菜单：S / M / L 三选一 |
| 删除 widget | 触发 toast 撤销删除流程 |

### 3.4 可用性

- 编辑态和非编辑态都可用
- 在鼠标右键的位置弹出
- 点击菜单项 / 点击外部 / ESC → 关闭菜单

### 3.5 去除

- **去掉 widget 三点菜单**（编辑态不再显示三点按钮）
- **去掉 widget 编辑态删除按钮**（所有变种）

## 4. 删除交互（Toast 撤销）

### 4.1 流程

```
右键菜单点击"删除"
        ↓
立即从 UI 移除（乐观更新）
        ↓
底部弹出 toast：「已删除「xxx」 [撤销]」
        ↓
   ┌─────────┴─────────┐
   │                     │
5 秒内点击"撤销"      5 秒超时
   │                     │
恢复到原位置         调用 API 持久化删除
（乐观更新回滚）     toast 自动消失
```

### 4.2 视觉规范

| 属性 | 值 |
|---|---|
| 位置 | 底部居中（距底部 24px） |
| 背景 | `bg-slate-900 dark:bg-slate-100` |
| 文字 | `text-white dark:text-slate-900` |
| 撤销按钮 | 主色（`text-primary`），加粗 |
| 动画 | 从底部滑入（200ms ease-out） |
| 时长 | 5 秒 |

### 4.3 多个删除

- 每个删除独立 toast，不叠加
- 新删除不中断旧删除的撤销窗口

### 4.4 替换

- **去掉所有 `useImperativeDialog` 在删除场景的使用**（保留其他场景如重置等）
- 卡片和 widget 删除统一走 toast 撤销

## 5. 拖拽规范

### 5.1 防误触

统一 dnd-kit `PointerSensor` + `activationConstraint: { distance: 8 }`：

```ts
const sensors = useSensors(
  useSensor(PointerSensor, {
    activationConstraint: { distance: 8 },
  }),
);
```

按下后移动 8px 才进入拖拽，点击/右键不受影响。

### 5.2 widget（RGL）技术评估

RGL 内部用 `react-draggable`，不一定支持 dnd-kit 风格的 distance 阈值。实施时按以下优先级评估：

| 方案 | 说明 |
|---|---|
| A（优先） | RGL 配置层是否支持 distance 阈值 |
| B | 包裹层拦截 pointer 事件，手动实现 distance 判断 |
| C（兜底） | 保留 RGL 默认，接受 widget 侧策略不一致 |

### 5.3 拖拽手柄

| 资源 | 拖拽手柄 |
|---|---|
| 卡片 | 整卡可拖（无显式手柄） |
| widget | 整卡可拖 + 编辑态显示 resize 把手（右下角） |

### 5.4 跨容器

| 资源 | 跨容器支持 |
|---|---|
| 卡片 | 支持跨分类拖拽（dnd-kit 多 DroppableContext） |
| widget | 单容器内排序（RGL bin-packing） |

## 6. 编辑态视觉反馈

### 6.1 统一样式（卡片 + widget）

```css
.edit-mode-item {
  ring-1 ring-slate-900/10 dark:ring-white/10;
  shadow-md;
  cursor-grab; /* hover 时 */
}
```

**不用 scale，也不 dim 壁纸**：缩小会让壁纸从缝隙突兀露出；dim 壁纸会让卡片蒙上半透明遮罩感。编辑态用顶部提示条（`EditModeBanner`）从顶部滑入，显示「编辑模式 · 拖拽排序 · ESC 退出」，卡片/widget 自身不做任何视觉装饰，背景保持不变。提示条用 `pointer-events-none` 不阻挡交互，配合 FloatingToolbar 按钮文字变为「完成」双重提示。

### 6.2 widget 额外

- resize 把手（右下角，编辑态显示，非编辑态隐藏）
- RGL 占位符（拖拽时显示，虚线边框 + 半透明背景）

### 6.3 弱化 widget 编辑态

当前 widget 编辑态比卡片"更闹"（三点菜单 + 删除按钮 + resize 把手 + 占位符动画）。统一后：

| 元素 | 处理 |
|---|---|
| 三点菜单 | **删除** |
| 删除按钮（所有变种） | **删除** |
| resize 把手 | **保留**（编辑态显示） |
| 占位符 | **保留**（拖拽时显示，样式克制） |
| ring/scale/shadow | **对齐卡片**（统一到上述样式） |

### 6.4 去除文案

- 去掉"拖拽排序 · hover 卡片删除"等提示文案
- 编辑模式下 FloatingToolbar 显示"完成"按钮即可，不加额外说明

## 8. 交互流程图

### 8.1 编辑模式

```
用户点击 FloatingToolbar"编辑"
        ↓
卡片 + widget 同时进入编辑态（ring/scale/shadow）
        ↓
用户拖拽排序 / 调整 widget 尺寸
        ↓
用户 ESC / 点击"完成"
        ↓
卡片 + widget 同时退出编辑态
```

### 8.2 删除（右键 + toast 撤销）

```
用户右键卡片/widget
        ↓
弹出 ContextMenu（编辑 / 资源特有 / 删除）
        ↓
点击"删除"
        ↓
立即从 UI 移除 + 底部 toast「已删除 [撤销]」
        ↓
   ┌─────────┴─────────┐
   │                     │
点击"撤销"            5 秒超时
   │                     │
恢复原位置           持久化删除
```
